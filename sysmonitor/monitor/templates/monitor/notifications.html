💬 WhatsApp Setup (Meta Cloud API)

Step 1 — Create Meta Developer Account

  1. Go to developers.facebook.com and log in with Facebook
  2. Click My Apps → Create App
  3. Choose Business type → give it a name → Create

Step 2 — Add WhatsApp Product

  1. In your app dashboard, click Add Product
  2. Find WhatsApp → click Set Up
  3. You'll get a free test phone number instantly

Step 3 — Get Your Credentials

  1. Go to WhatsApp → API Setup
  2. Copy Phone Number ID → paste in the form above
  3. Copy Temporary Access Token (or generate a permanent one)
  4. For permanent token: Go to System Users in Business Settings → generate token with whatsapp_business_messaging permission

Step 4 — Add Test Recipients

  1. Under API Setup, add recipient phone numbers to the allowed list
  2. Each number must send "hello" to your test number first to opt in
  3. Format: +8801711234567 (with country code, no spaces)

⚠️ Free Tier Limits

  • 1,000 free conversations per month (more than enough for outage alerts)
  • Test mode: only pre-approved numbers can receive messages
  • Production: verify your business to send to anyone
✈️ Telegram Bot Setup (Easiest & Free)

Step 1 — Create a Bot (takes 2 minutes)

  1. Open Telegram and search for @BotFather
  2. Send /newbot
  3. Give your bot a name: e.g. NanoLab Monitor
  4. Give it a username: e.g. nanolab_monitor_bot
  5. BotFather gives you a token like 1234567890:ABCdef... — copy it

Step 2 — Get Your Chat ID

  1. Search for your bot in Telegram and send it any message (e.g. "hello")
  2. Paste the Bot Token in the Telegram section above and save
  3. Click Find Chat IDs — it will show all chats that messaged your bot
  4. Copy your Chat ID and use it when adding a recipient

Step 3 — Group Notifications (Optional)

  1. Create a Telegram group, add your bot to it
  2. Make the bot an admin
  3. Send a message in the group, then click Find Chat IDs — group ID starts with -100...
📧 Gmail SMTP Setup

Step 1 — Enable 2-Factor Authentication on Gmail

  1. Go to myaccount.google.com → Security
  2. Enable 2-Step Verification if not already on

Step 2 — Create an App Password

  1. Go to myaccount.google.com → Security → App Passwords
  2. Select App: Mail, Device: Other → type "SysMonitor"
  3. Click Generate — you get a 16-character password like abcd efgh ijkl mnop
  4. Paste this in the App Password field above (not your Gmail password)

Step 3 — Fill the Form

  • SMTP Host: smtp.gmail.com
  • SMTP Port: 587
  • Gmail Address: your Gmail (e.g. nanolab.alerts@gmail.com)
  • App Password: the 16-char password from Step 2
  • From: NanoLab Monitor <nanolab.alerts@gmail.com>
