Safe maintenance path

The maintenance reference describes where code lives, not permission to modify live data.

1 · Locate

Find the page or service owner in the file catalog; confirm URL and role policy.

2 · Review

Examine source and call sites privately, identify security consequences and preserve backups.

3 · Validate

Use clean release worktree, isolated Django tests, source hash and browser acceptance.

4 · Publish

Push an approved, non-force Git commit, deploy backup-first to both sites, verify services and retain rollback.

5 · Document

Update Security Patch Updates, Manual, release notes and sanitized Windows source archive.

6 · Recover

If checks fail, stop. Recover from the verified rollback after reviewing the impact; do not delete unknown files.
